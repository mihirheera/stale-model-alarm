        Plain-English glossary
        Fiscal year (FY)
        The government's year, October to September. FY2006 = Oct 2005 to Sep 2006.
        Default / charged off
        The bank gave up collecting and wrote the loan off as a loss.
        Model predicted
        The average chance of default the loan model gave this year's loans.
        Actual ÷ predicted
        1.0× = the model expected the right number of defaults. 2.0× = twice as many defaulted as it expected.
        Drift score
        A second AI tries to tell this year's applications from the training years' (never seeing which loans defaulted). 0.5 = it can't tell; near 1.0 = very different.
        AUC
        How well the model ranks risky loans above safe ones. 0.5 = a coin flip, 1.0 = perfect.
        Brier score
        How far the predicted percentages were from what happened. Lower is better.
        PSI
        The banking industry's standard check for how much one application detail (like loan size) has shifted.
        Label monitor
        A simpler alarm: count how many loans approved two years ago have already defaulted.
        Too early to judge
        Many of these loans were still running when the data ends (2014), so we can't fairly judge the model.
