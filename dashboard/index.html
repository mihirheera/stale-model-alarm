For a community-bank credit-risk analyst reviewing a loan model. Model 1 predicts each loan's default risk. Model 2 checks, from application forms alone, whether this year's applicants still resemble the ones Model 1 was built from. This is a retrospective replay of historical SBA loans, not a deployed system.

Model health overview

Drift is not failure. A drift alert means the model is being used on applicants unlike the ones it was built from. It does not by itself mean defaults will rise or that the model is wrong.
